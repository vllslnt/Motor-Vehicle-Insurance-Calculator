# Motor Vehicle Insurance Calculator

A web-based calculator for estimating Indonesian motor vehicle insurance premiums based on OJK Circular Letter No. 6/SEOJK.05/2017.

## Features

- Vehicle information input form
- OJK premium calculation based on all-risk or total loss only (TLO) coverage
- Option to include additional coverages
- Front-end calculation
